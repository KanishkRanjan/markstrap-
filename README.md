# MarkStrap pitch website

A buildless eight-slide presentation. Serve `dist/` with any static HTTP server or open the hosted Site.

## Presenting

- Left / right arrow, Page Up / Down, or Space: navigate.
- F: fullscreen. O: overview. N: speaker notes.
- Pause button: stop the background animations. Reduced-motion settings are respected.
- Slides can be opened directly with `#1` through `#8`.
- Swipe horizontally on the background to navigate on touch devices.
- The evidence links and closing evidence dialog document sources and assumptions.

## Content status

The campaign walkthrough and technical architecture are proposed behavior, not a live campaign service. Cost figures are adjustable illustrations. No customer traction or performance improvements are claimed. The team slide is deferred at the user's request.

## Editing

- Slide content: `dist/index.html`.
- Speaker notes, demo scenarios, controls: `dist/app.js`.
- Visual design and responsive layouts: `dist/style.css`.
- Code-native animated ASCII hands: `dist/assets/hands.js`.
